# ESP32-P4 双核占用率实测（2026-11-10）

固件使用 ESP-IDF 5.4 的 FreeRTOS 运行时间统计；每约 1 秒读取两个核的 idle task 计数器，计算该区间内的总占用率。数值包括取帧、USB、图片编码和解码等任务，不代表单个函数或某帧耗时。

实机为 COM57（FS 日志）和 COM60（HS CDC），OV9281 前放置可解出 `012345` 的 DataMatrix。刷入 `build/p4scan_ov9281.bin` 后，COM57 连续 20 秒得到 19 次有效采样，Core 0 中位数 10.0%（9.8%～10.5%），Core 1 中位数 100.0%（99.4%～100.0%）；期间持续解码，无重启。原始记录见 [board_cpu_usage.log](decode_stages/board_cpu_usage.log)。此段无调试器图片请求。

随后用 HS CDC 按“上传开→关→开→关”交替测试，每段预热 2 秒、采样 6 秒：

| 图片上传 | Core 0 中位数 | Core 1 中位数 | 成功结果/秒 | 解码耗时中位数 |
| --- | ---: | ---: | ---: | ---: |
| 开，第 1 段 | 21.1% | 99.5% | 42.33 | 20.52 ms |
| 关，第 2 段 | 13.3% | 100.0% | 45.33 | 20.44 ms |
| 开，第 3 段 | 21.4% | 99.7% | 42.33 | 20.57 ms |
| 关，第 4 段 | 13.3% | 100.0% | 45.33 | 20.45 ms |

每段有 6 次 CPU 采样；原始汇总见 [cpu_upload_benchmark.json](cpu_upload_benchmark.json)。图片上传使 Core 0 多占用约 8 个百分点，主要来自按需 JPEG/CDC 传输；Core 1 在两种状态下都接近满载。此现场条件下，关图使每秒成功结果从 42.33 增至 45.33，单次解码耗时变化很小。

新版 `dist/P4ScanOV9281Debugger.exe` 已分别以开图和关图模式连接 COM60 做 10 秒自动验证：开图收到 27 张同帧图片和 406 条成功定位，关图收到 0 张图片和 435 条成功定位；两种模式的界面均显示实时双核占用率。截图见 [开图界面](cpu_ui_smoke/window.png) 和 [关图界面](cpu_ui_smoke_no_images/window.png)。
