# P4 与电脑端姿态解算对齐（2026-11-17）

## 标定与坐标定义核对

`port/standalone_idf_test/main/scan_pose.c` 默认值、
`tools/ov9281_debugger/geometry.py::default_ov9281_calibration()`、
`tools/ov9281_debugger/calibration_template.json` 和 `参考资料/ost(1).txt` 相同：

| 项目 | 数值 |
| --- | --- |
| 图像宽、高 | 1280 × 720 |
| fx、fy | 733.242515、732.511533 |
| cx、cy | 589.273600、359.376026 |
| k1、k2、p1、p2、k3 | 0.119448、−0.223125、0.000163、−0.000596、0.083362 |

P4 使用 float，电脑端使用 double，默认标定仅有对应浮点表示的舍入差异。
这是源码默认值核对，不是读取设备当前 NVS；运行时的 Flash 标定仍按原逻辑保留。

双方都使用 P0→P1→P2→P3 的码体身份顺序，码体坐标依次为
`(-s/2,+s/2,0), (+s/2,+s/2,0), (+s/2,-s/2,0), (-s/2,-s/2,0)`。
三角度的公式相同：`pitch=asin(R12)`、`yaw=atan2(-R02,-R22)`、
`roll=atan2(R10,-R11)`，正对码面时为 0°。
P4 仍按内容首字符选择边长：0 为 30 mm，1 为 50 mm。

## 修改

原 P4 在去畸变、解单应矩阵并将旋转正交化后直接输出。
电脑端在 IPPE 初始化后还使用 OpenCV LM 精修，并按重投影误差选择姿态。
四个角点有噪声时，直接分解单应矩阵不能得到最小像素误差的物理姿态。

P4 现在保留原来的初始化，在此基础上加入六参数阻尼最小二乘精修：

- 直接在原始像素坐标中比较四个角点，投影包含全部五个畸变系数。
- 使用解析雅可比和 6×6 方程，旋转增量通过 Rodrigues 公式更新，保持正交性。
- 平移增量按光轴深度缩放，改善旋转和平移参数的数值条件。
- 对绕中心视线反射的法向候选再次精修，按较小重投影误差选择。若候选替换了初始解，再检查一次，避免远距离含噪小码的初值偏差。
- 每次精修最多 40 轮，候选检查最多两轮；残差不再改善时提前结束。
- 使用单精度、固定大小栈数组，无堆分配、无历史帧依赖、无时间平滑。
- `scan_pose_result_t` 增加内部 `reprojection_px` 诊断值，UART 17 字段格式不变，`compute_us` 继续记录完整姿态计算耗时。

没有修改或重新打包原 P4ScanOV9281Debugger。AGV_3D_Test 的原始参数卡直接显示 UART 数值，3D 的偏航时间滤波属于显示处理。

## 同角点验证

命令：`py -3.12 tools/validate_scan_pose.py`。
脚本用 Visual Studio C 编译器直接编译实际 `scan_pose.c`，只用桩替换 ESP/NVS 平台服务；
通过 ctypes 与原电脑端 `geometry.py` 的 OpenCV 解算作比较。
结果保存在 `build/pose_validation/report.json`。

截图角点为 `(521.288,287.283), (574.915,294.349), (569.467,346.858), (515.192,340.729)`，边长 30 mm：

| 参数 | OpenCV 原始计算 | 优化后 P4 C 代码（主机运行） |
| --- | ---: | ---: |
| yaw_y / ° | −7.688700 | −7.688659 |
| pitch_x / ° | −7.215182 | −7.214798 |
| roll_z / ° | +6.645770 | +6.645761 |
| range_m | 0.407455559 | 0.407455862 |
| optical_depth_m | 0.406060011 | 0.406060338 |
| distance_to_plane_m | 0.399513064 | 0.399513930 |
| tx / m | −0.024286253 | −0.024286285 |
| 重投影 RMS / px | 0.123560 | 0.123562 |

共 801 组，包含截图及 800 组 30/50 mm、距离 0.18～1.2 m、不同位置和姿态、
0/0.05/0.2/0.5 px 噪声的输入；801 组全部通过角度差 ≤0.1°、距离差 ≤0.2 mm 的检查。
实际三项角度最大差约 0.0131°，距离最大差约 0.156 mm。
此外验证了非有限角点、全重合角点、越界角点及不支持的尺寸前缀会被拒绝。

主机平均每次调用约 20 µs、P95 约 28 µs（包括 ctypes 调用）；**不是 P4 实机耗时**。
这些结果验证两种解算的一致性，不代表真实测量的绝对精度。
平面小码仍存在姿态二义性，标定误差、角点误差和码体变形仍可能影响现场角度。
