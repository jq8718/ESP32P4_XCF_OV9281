# 2026-11-19 无码搜索优化固件

基线：`773bd2ecd5280f460488f1ff7b2657ac728f68a7`（整机测试版）。

本版本取消相同二值图的重复全图搜索，增加小码候选四侧白边检查，减少外标记重叠扫描，并在外标记长循环中执行本帧超时退出；6px 搜索临时缓冲从 128400 字节降至 78966 字节。每帧独立搜索。

现场无码平均处理延迟由 110.86 ms 降至 91.05 ms，本次最大值由 162.60 ms 降至 108.60 ms；当前完整有码实测成功率 99.43%，成功吞吐 17.50 帧/秒。当前场景未达到 40 帧/秒。

历史变换回归 1185 项未新增失败；59 张附加样本及 ASan/UBSan 检查通过；140 次超时路径检查未发现泄漏。

详细测试条件、统计口径与图片上传测试限制见 [测试报告](../../../docs/failure_diagnosis/no_code_latency_20261119/REPORT.md) 和 [测量数据](../../../docs/failure_diagnosis/no_code_latency_20261119/measurements.json)。
